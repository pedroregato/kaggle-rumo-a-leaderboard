# kaggle-rumo-a-leaderboard

Estudos sobre as soluções dos primeiros colocados em competições do Kaggle.

## Conteúdo

- `comparacao-top3-make-data-count.md`: comparação das estratégias dos 3 primeiros lugares da competição [Make Data Count - Finding Data References](https://www.kaggle.com/competitions/make-data-count-finding-data-references).
- `leaderboard-top10-private.csv`: top 10 do leaderboard privado (posição final, lida em 20/09/2026).
- `EDU-MDC-001-evidence-lab-plan.md`: plano completo para criação de um Evidence Lab do TIL (Text Intelligence Lab) baseado no caso Make Data Count.
- `kaggle-competicoes-alinhadas-ao-til.md`: levantamento de outras competições do Kaggle alinhadas às aulas do TIL, com sugestões de uso em futuros Evidence Labs.

## Observação

A análise se baseia nos writeups oficiais dos três primeiros lugares e no notebook público do 1º lugar. O 2º e o 3º lugar não linkaram código.
